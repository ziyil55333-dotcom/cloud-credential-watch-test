# 独立评审回执填写方式

请在本目录新增 Markdown 文件，文件名用账号、任务编号和实际日期。同账号同日多次回填时，文件名再加序号。提交分支为 `codex/review-handoff`。

每份回执记录以下信息。

- **任务编号**填写 `extension-review` 或 `blind-preflight`。
- **执行账号和日期**填写实际账号与记录日期。
- **状态**填写进行中、待确认、已完成或受阻。
- **已验证结果**写实际可核实的结论。接入任务可写三轮告警数、首报时间是否一致、核心指纹是否一致、实际用时及是否由评审人核对。盲测准备任务按六入口写就绪或缺项。
- **待处理项**写缺哪份记录、哪项权限或哪次核对。
- **原始证据交接**可写压缩包文件名、SHA-256 和是否已私下交接。

此目录公开可读。这里只回填脱敏摘要。完整证据包、盲测样本和期望答案、账号凭据、设备路径通过双方约定的私下渠道交接。
