# 独立评审回执填写方式

在本目录新增一份 Markdown，文件名包含执行账号、任务编号和日期，提交至 `codex/review-handoff`。

- **任务编号**填写 `extension-review`、`blind-preflight` 或 `blind-review`。
- **执行账号和日期**填写实际执行账号与记录日期。
- **状态**填写进行中、待确认、已完成或受阻。
- **已验证结果**填写实际可核实的结论。接入任务记录三轮告警数、首报时间、核心指纹、用时及评审人核对情况。盲测准备逐个记录六入口的基线和权限。正式盲测记录是否已封存、各入口的实际发布数量以及通过、失败或未执行的数量。
- **待处理项**写明缺少的记录、权限或操作，并标注受影响的入口。
- **原始证据交接**可以填写压缩包文件名、SHA-256 和是否已私下交接。

本目录公开可读，只收脱敏摘要。完整证据包、盲测样本、预期答案、账号凭据和设备路径留在双方约定的私下渠道。
