# 独立评审交接站

交接分支为 `codex/review-handoff`，任务与回执放在 `review-handoff/`。使用已获授权的 GitHub 账号读取任务并提交结果。这个仓库公开可读，完整证据包、盲测标签、样本值、账号凭据和电脑本地路径通过双方约定的私下渠道交接。

公告源接入由评审人本人确认实际参与情况。若原轮缺少独立评审人的参与或见证，保留原记录，另开一轮复测。公开 GitHub 复测无需重复。

## 读取与回填

1. 读取本页任务编号。具体执行使用项目方提供的 v17 评审包和本次对话授权。
2. 在 [回执目录](results/README.md) 新增 Markdown 文件，提交到 `codex/review-handoff`。文件名写账号、任务编号和日期。后续更新可新增回执，保留历史。
3. 把回执的 GitHub 链接或提交 SHA 发给项目负责人。负责人根据私下收到的原始证据核验。

只在项目方自有或获授权的测试资产操作。公开发布使用未签发合成样本。回执用于交接，不触发自动运行。
